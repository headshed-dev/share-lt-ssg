## Development

The dev container runs `sleep infinity` and nothing else. Do **not** start, stop, or
background the dev server — the user runs `npm run dev` themselves inside
`make shell`. Never leave a dev server running in the background; if a stale lock
blocks startup, clear it with `astro dev stop`.
